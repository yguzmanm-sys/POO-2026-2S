## Descripción del Repositorio

Este repositorio contiene el desarrollo de las actividades asignadas para la asignatura **Programación Orientada a Objetos**. Las soluciones han sido implementadas en **Python** aplicando rigurosamente los principios del paradigma orientado a objetos (clases, atributos, métodos, encapsulamiento, tipos enumerados y modularidad), junto con la documentación completa en **LaTeX** y sus correspondientes diagramas de clases UML.
