# Actividad 1 - Programación Orientada a Objetos (2026-2S)

Este directorio contiene la solución a los ejercicios de la **Actividad 1** de la asignatura **Programación Orientada a Objetos**, implementados bajo el paradigma orientado a objetos (POO) en Python, junto con su respectiva documentación en LaTeX (`actividad1_POO_2026.tex`) con diagramas de clases UML.

---

## Contenido

| Archivo | Tipo de Ejercicio | Descripción | Clase Principal |
| :--- | :--- | :--- | :--- |
| `ejercicio_resuelto4_edades.py` | Resuelto 4 | Cálculo de edades de Juan, Alberto, Ana y la madre | `FamiliaJuan` |
| `ejercicio_resuelto5_seguimiento.py` | Resuelto 5 | Prueba de escritorio y seguimiento de instrucciones | `SeguimientoInstrucciones` |
| `ejercicio_propuesto12_salario.py` | Propuesto 12 | Cálculo de salario bruto, retención y salario neto | `Empleado` |
| `ejercicio_propuesto14_potencias.py` | Propuesto 14 | Cálculo del cuadrado y el cubo de un número | `Numero` |
| `ejercicio_propuesto17_circulo.py` | Propuesto 17 | Cálculo del área y longitud de la circunferencia | `Circulo` |
| `actividad1_POO_2026.tex` | Documento | Documento en LaTeX con enunciados, códigos y diagramas UML | N/A |

---

## Ejecución de los scripts

Para ejecutar cualquiera de los ejercicios, se requiere Python 3.x:

```bash
python ejercicio_resuelto4_edades.py
python ejercicio_resuelto5_seguimiento.py
python ejercicio_propuesto12_salario.py
python ejercicio_propuesto14_potencias.py
python ejercicio_propuesto17_circulo.py
```
